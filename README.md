# Polyu storyworld

This repository is a collection of yaml files that describe a storyworld collectively imagined by the students of SD5967.

## Add your contribution

To add your character to the storyworld, create a pull request with the yaml files you would like to add.
A pull request may contain more than one character.

### Step 1

Fork this repository. You or your group need to fork this repository to create a pull request.

### Step 2

Clone **your fork** of this repository.

### Step 3: Open in VS Code

After cloning your fork, you can open it in Visual Studio Code using one of these methods:

#### Method 1: Using Command Line

Navigate to the cloned repository directory and open it in VS Code:

```bash
cd polyu-storyworld
code .
```

#### Method 2: Using VS Code GUI

1. Open Visual Studio Code
2. Click **File** → **Open Folder** (or **File** → **Open** on macOS)
3. Navigate to and select your cloned `polyu-storyworld` folder
4. Click **Open** or **Select Folder**

#### Recommended VS Code Extensions

For the best YAML editing experience, consider installing:
- **YAML** by Red Hat - Provides YAML language support with validation and auto-completion
- **Prettier** - Code formatter that supports YAML files

To install extensions:
1. Click the Extensions icon in the left sidebar (or press `Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Search for the extension name
3. Click **Install**

#### Working with Character Files

Once opened in VS Code:
- Navigate to the `characters` folder in the Explorer sidebar
- Create a new file named with the last 4 digits of your student ID (e.g., `1234g.yaml`)
- Use the existing character files as templates for the required fields: `name`, `age`, `personality`, `appearance`, and `backstory`

### Step 5

**Commit** and **publish** your yaml files to your fork of this repository on github

**Each character yaml file should be named with the last 4 digits of your student id**

Example:

```
characters/6166r.yaml
```

You can commit and push from VS Code:
1. Click the Source Control icon in the left sidebar (or press `Ctrl+Shift+G` / `Cmd+Shift+G`)
2. Stage your changes by clicking the **+** icon next to your file
3. Enter a commit message describing your character
4. Click the **✓** Commit button
5. Click **Sync Changes** or **Push** to publish to GitHub

### Step 6

When you are happy with your contribution, create a pull request for the main repo `venetanji/polyu-storyworld`
